# Offline validation and remaining prerequisites

These checks concern the public adaptation, not a new OCR measurement.
They ran without contacting an OCR host, downloading packages, or executing the banner script.
Temporary test files were created inside this repository and removed by the tests.

## Artifact checks

- The published measurement JSON matches every supplied numerical value and per-page score after removal of run labels and absolute timestamps.
- LICENSE and `.gitignore` are byte-identical to the supplied templates.
- The banner source differs only in the requested display text; its drawing code was not executed.
- Python sources compile; public text has no CJK or machine-specific host, account, or home-path literals.
- Supplied legal/template public credits are retained. Repository links use the required absolute public URLs.

## What is not validated here

PyMuPDF and rapidfuzz were absent from the available Python environment.
The scorer's exact stdlib fallback was exercised; actual PDF rendering and parsing were not.
Pillow and NumPy were discoverable, but their rendering path was not exercised without PyMuPDF.
No packages were downloaded to fill those gaps.

There was no GPU run, container-image build, remote deployment, or text-engine installation.
The image recipe, SSH authentication, GPU passthrough, workspace permissions, and cleanup permissions remain prerequisites for a reader's real run.
The dated synthetic measurement tables are supplied historical evidence, not validation of this adapted runtime.

The exact original Office fixture generators and historical OCR Markdown/monitoring logs were not supplied for publication.
The text-engine result tables are retained with their dates, but those probes and the historical aggregate cannot be regenerated byte-for-byte from this repository alone.
The raw-log aggregator is tested with synthetic logs; numerical historical results are preserved separately.
No private store adapter is shipped; the downstream seam is tested against a mock store.
